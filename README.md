# 🌐 Tecnologias Web (TWEB) - ADS

Repositório oficial com os códigos e materiais práticos da disciplina de **Tecnologias Web**, do curso de Análise e Desenvolvimento de Sistemas (S1) no **IFCE Campus Boa Viagem**.

## 🎯 Objetivo
Centralizar todos os códigos desenvolvidos em laboratório, servindo como material de estudo, consulta e referência para as avaliações e projetos práticos.

---

## 🛠️ Ferramentas e Ambiente de Desenvolvimento

Para acompanhar as aulas práticas, utilizamos o **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)**. 

Para manter o nosso ambiente padronizado e produtivo, instale as seguintes **Extensões Essenciais** no seu VS Code:

- **[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer):** Cria um servidor local e atualiza a página no navegador automaticamente a cada vez que salva o arquivo (`Ctrl + S`).
- **[Prettier - Code Formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode):** Formata e organiza o código automaticamente, mantendo um padrão limpo.
- **[Auto Rename Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag):** Altera automaticamente a tag de fechamento quando modifica a tag de abertura.
- **[Auto Close Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-close-tag):** Fecha as tags HTML automaticamente.
- **[Indent-Rainbow](https://marketplace.visualstudio.com/items?itemName=oderwat.indent-rainbow):** Colore a indentação para facilitar a leitura visual e entender onde os blocos de código começam e terminam.

---

## 📂 Organização do Repositório

Este repositório está organizado de forma cronológica para facilitar os seus estudos. 

Todo o conteúdo está centralizado na ramificação principal (`main`). **Para cada novo laboratório ou aula prática, será criada uma pasta específica** contendo os códigos e arquivos desenvolvidos naquele dia. 

Basta navegar pelas pastas do repositório para encontrar o material prático correspondente a cada assunto abordado em sala de aula!
